# Mobile Phone Sales Dashboard | Power BI

## Project Overview

This project is a Power BI dashboard created to analyze mobile phone sales data. The dashboard provides insights into sales performance, customer preferences, and product trends.

## Objective

* Analyze mobile phone sales data
* Understand brand-wise and model-wise performance
* Track sales trends and key business metrics
* Create interactive visualizations using Power BI

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Excel (Dataset)

## Dashboard Features

* KPI cards for total sales and performance metrics
* Brand-wise sales analysis
* Model-wise comparison
* Price and category analysis
* Interactive filters and slicers

## Data Cleaning

Performed data preparation using Power Query:

* Removed duplicate values
* Handled missing data
* Changed data types
* Prepared data for visualization

## Key Insights

* Identified top-performing mobile brands
* Compared sales across different models
* Analyzed customer buying patterns

## Conclusion

This dashboard demonstrates data cleaning, visualization, and business intelligence skills using Power BI.
