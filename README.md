# Sales Dashboard (Power BI)

## 📌 Project Overview
This project focuses on sales analysis using Power BI. An interactive dashboard was created to visualize sales performance and business insights.

## 🛠 Tools Used
- Power BI
- Excel

## 📊 Features
- Sales Analysis
- Region-wise Performance
- Interactive Filters and Visuals
- Profit Insights

## 📈 Outcome
The dashboard helps in understanding sales trends and supports better decision-making.
